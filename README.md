# الحضور والانصراف

أبلكيشن موبايل (يشتغل من المتصفح ويتثبت على الشاشة الرئيسية) بيقرا ملف جهاز البصمة ويحسب:
ساعات العمل، التأخير (بعد فترة سماح)، الانصراف بدري، الزيادة، الغياب والإجازات — مع أذونات التأخير والانصراف.

- بيتعرف على الشيفت (صباحي/مسائي) لوحده من أول بصمة.
- بيقرا تقرير الجهاز (xls) أو سجل البصمات الخام (attlog / Excel / CSV).
- تقارير شامل أو مفصّل، لكل الموظفين أو لموظف واحد، وتصدير Excel.
- كل البيانات محفوظة على الموبايل بس، ومفيش أي بيانات بتترفع على سيرفر.

مكتبة قراءة/كتابة Excel: SheetJS Community Edition (Apache-2.0) — `vendor/`.
