# الحضور والانصراف

تطبيق أندرويد بيقرا ملف جهاز البصمة ويحسب لكل موظف: ساعات العمل، التأخير (بعد فترة سماح)، الانصراف بدري، الزيادة، الغياب، الغياب بإذن والإجازات.

## التنزيل
آخر نسخة: صفحة **Releases** ← `attendance.apk`. سطّبها فوق القديمة، والبيانات بتفضل.

ونفس التطبيق شغال من المتصفح كمان: https://ahmedmogahed2020.github.io/attendance-app/

## الشاشات
- **اليوم:** كل الموظفين في يوم واحد — حاضر / غياب / غياب بإذن / إجازة، وأوقات الحضور والانصراف تتعدل مكانها، وأزرار "كلهم حضور بمواعيد الشيفت" و"كلهم غياب"، وتنبيه بالأيام الناقصة يوديك لها.
- **الشهر:** تقرير شامل أو مفصّل لكل الموظفين أو لموظف، وتصدير Excel، والشهور القديمة بالأسهم.
- **الموظفين:** إضافة وتعديل (يوم الإجازة، الشيفت الثابت أو التلقائي، بداية وترك الشغل) وحذف.
- **الإعدادات:** ملفات الجهاز، الاعتماد على الجهاز من يوم، النسخ الاحتياطي (يدوي وتلقائي)، الشيفتات وقواعد الحساب.

## المميزات
- بيعتمد على بصمة الحضور وبصمة الانصراف من الجهاز، وبيعرف الشيفت (صباحي/مسائي) لوحده.
- الأيام الناقصة بتستنى تسجيلك: وقت حضور أو انصراف ناقص، أو غياب / غياب بإذن / حضور وانصراف يدوي.
- كل شهر بيفتح لوحده، والشهور القديمة محفوظة وتقدر تطلّع تقاريرها.
- تقارير شامل أو مفصّل، لكل الموظفين أو لموظف واحد، وتصدير Excel.
- إضافة موظف جديد، أو تسجيل تاريخ ترك الشغل، أو حذف نهائي.
- كل البيانات على الموبايل بس (مع نسخة احتياطية).

## البناء
كل push على `main` بيبني APK موقّع تلقائي من GitHub Actions وينشره كـ Release.
- الواجهة: `index.html` و`app.js` و`engine.js` (الحسابات) — ونفس الملفات بتتنشر على GitHub Pages.
- الغلاف: Capacitor 7 (`android/`)، و`npm run sync` بينسخ الواجهة لـ `www/`.
- مكتبة Excel: SheetJS Community Edition (Apache-2.0) في `vendor/`.
